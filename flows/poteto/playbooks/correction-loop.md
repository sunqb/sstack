# 把一次纠正变成一条检查

不要把「下次别这样」写进 markdown 就算完事。按这个顺序做：

1. **复现**：用最小步骤说明 agent 或人刚刚做错了什么，以及用户能看见的后果。
2. **先写一条会失败的检查**：lint 规则、类型收紧、回归测试、TLA+ 不变性，或 `verify.d` 钩子。此时 `bash scripts/verify.sh` 必须红。
3. **再修代码**，直到这条检查变绿，且没有削弱其他检查。
4. **只在 `docs/corrections.md` 留一行对照**：日期、纠正了什么、检查的位置、状态为「已强制」。
5. 若同类错误再次出现，说明检查不够强：收紧规则，而不是再写一段教训。

禁止另建 `LESSONS.md`。没有强制力的条目不要留在对照表里。
