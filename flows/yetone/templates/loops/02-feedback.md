# Loop 2：公开反馈入口

结构来自 yetone 公开的第二条 `/loop`（主帖截图的转写）。作者在 Magpie 上使用便宜决策模型（他举例 jev）先判断「是不是本产品的反馈」，以免把无关内容交给主模型。你的产品名若不容易撞车，过滤器可以更简单，但「先过滤再交给贵模型」这一步值得保留。

```
盯一下公开网络上关于本产品的反馈。先用便宜的决策模型判断：这条内容是否真的在谈本产品、是否属于产品反馈。若不是，直接忽略，不要把原文转发给主模型。

如果是有价值的建议，或是真实可复现的缺陷，再去做实现或修复。完成后上线，并回复原来的那条反馈。
```

修之前在用户实际使用的环境里复现。做完后在提交说明里写清跑过什么。
